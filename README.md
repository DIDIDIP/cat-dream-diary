# 고양이의 꿈 일기

졸린 고양이가 잠들기 전 60초 동안 가방에 물건 2개를 챙기고, 꿈속에서 **딱 세 번** 골라 아침을 맞이하는 선택지 이야기 게임이에요.

**플레이:** https://dididip.github.io/cat-dream-diary/

## 조작
- 마우스 또는 터치
- 키보드: `A`·`B`·`C` 또는 `1`·`2`·`3` = 선택, `Space` = 다음, `R` = 다시 시작
- 준비 단계에서는 `1`~`5`로 물건 챙기기

## 규칙
- 용기·배부름·졸음 수치에 따라 결말 5가지 중 하나가 나와요.
- 점수 = 용기×20 + 배부름×10 + (6−졸음)×15 + 결말 보너스

파이썬 tkinter 버전(`c05.py`)을 HTML·JavaScript 한 파일로 옮긴 버전이에요. 설치할 것은 없어요.
